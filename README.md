## Project question
Can a Pokémon's physical characteristics, battle statistics and type be used to predict whether it is Legendary?
This is a binary classification task. The target is `is_legendary` (about 9% positive, so the classes are imbalanced).

## Dataset
Kaggle: *Pokemon Stats Dataset* (shreyashautomation). 1,351 Pokémon, 20 columns.
Source, licence and citation details are in `data/README.md`.

## Summary of results
- Final model: a tuned Random Forest (200 trees, `class_weight="balanced"`, `max_depth=8`, `min_samples_leaf=1`), chosen with nested cross-validation before the test set was used.
- Cross-validated F1 on the training set: about 0.67 (about 0.61 when all forms of the same species are kept in the same fold).
- One-time test-set result (24 Legendary Pokémon in the test set): precision 0.52, recall 0.58, F1 0.55.
- Full results, error analysis and conclusions are in `notebooks/03_final_evaluation.ipynb` and the report.

## Setup
Tested with **Python 3.14.7** on Windows 11. Package versions are pinned in `requirements.txt`. Results can differ slightly with other scikit-learn versions (Random Forest in particular), so please use the pinned versions.

Windows (PowerShell), from the project folder:
```
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
macOS/Linux:
```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## Run
Run the notebooks in order: 01, 02, 03. Open them from the `notebooks/` folder (the default in Jupyter and VS Code). Each notebook looks for `data/pokemon.csv` in the current folder and then in its parent.

Interactive: use **Kernel > Restart & Run All** in each notebook.
```
.\.venv\Scripts\python.exe -m jupyter lab notebooks
```
Or execute headless, from the project folder (Windows):
```
.\.venv\Scripts\python.exe -m jupyter nbconvert --to notebook --execute --inplace notebooks\01_data_audit_and_baseline.ipynb
.\.venv\Scripts\python.exe -m jupyter nbconvert --to notebook --execute --inplace notebooks\02_model_comparison.ipynb
.\.venv\Scripts\python.exe -m jupyter nbconvert --to notebook --execute --inplace notebooks\03_final_evaluation.ipynb
```
Notebook 03 uses all CPU cores for tuning and takes about 1 to 2 minutes. On Windows, a headless run may print `KeyError ... resource_tracker` messages from joblib at the end of notebook 03. They are harmless clean-up messages and do not affect the results.

## Evaluation design (summary)
- Stratified 80/20 train/test split (`random_state=42`); the test set is not used for tuning and is evaluated once, at the end of notebook 03.
- 5-fold stratified cross-validation on the training set; tuning uses nested cross-validation.
- Metrics: precision, recall, F1 (Legendary class), plus accuracy and balanced accuracy.
- All preprocessing is inside a scikit-learn `Pipeline` to avoid data leakage.
- Excluded columns: `capture_rate`, `base_experience` (leakage), `is_mythical`, identifiers, `abilities`, `color`, `shape`.
- Robustness check: grouped cross-validation keeps all forms of the same species (for example Mega forms) in one fold.
