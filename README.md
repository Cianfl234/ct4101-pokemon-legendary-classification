# CT4101 ML Portfolio Project: Predicting Legendary Pokémon

Machine Learning portfolio project for CT4101 (University of Galway).
**Author:** Cian Flanagan (23391703)

## Project question
Can a Pokémon's physical characteristics, battle statistics and type be used to predict whether it is Legendary?
This is a binary classification task. The target is `is_legendary` (about 9% positive, so the classes are imbalanced).

## Dataset
Kaggle: *Pokemon Stats Dataset* (shreyashautomation). 1,351 Pokémon, 20 columns.
Source, licence and citation details are in `data/README.md`.

## Run

Then use **Kernel > Restart & Run All**. Run from inside the `notebooks/` folder (paths are relative: `../data/pokemon.csv`).
Alternatively, execute headless:
```bash
jupyter nbconvert --to notebook --execute --inplace notebooks/01_data_audit_and_baseline.ipynb
```

## Evaluation design (summary)
- Stratified 80/20 train/test split (`random_state=42`); the test set is not used for tuning.
- 5-fold stratified cross-validation on the training set.
- Metrics: precision, recall, F1 (Legendary class), plus accuracy and balanced accuracy.
- All preprocessing is inside a scikit-learn `Pipeline` to avoid data leakage.
- Excluded columns: `capture_rate`, `base_experience` (leakage), `is_mythical`, identifiers, `abilities`, `color`, `shape`.
